# MacList

**就在文件上传窗口里搜索，不切应用。**

MacList 0.3.0 Native Preview：一款本地优先、受 Listary 启发的 macOS 文件选择窗口助手。

[English](../README.md) · [流程规格](FILE_DIALOG_FLOW_SPEC.md) · [GitHub Actions](https://github.com/xffighting/maclist-actions/actions)

> [!IMPORTANT]
> 0.3.0 仍是原生开发预览版，不是已经完成兼容性验收的正式版。本地索引、双来源搜索、自动监听、贴附式搜索栏，以及失败关闭的“选中并确认”模式均已通过仓库静默门禁。真实系统面板、微信、Apple Mail、Outlook 可视化回归仍然暂停，因此这里不会写“已经兼容”。

## 它解决哪个时刻

你已经在微信聊天或邮件草稿里，点击了“上传文件 / 添加附件”。最麻烦的不是打开应用，而是在系统文件窗口里重新想目录、翻 Finder，或者只记得客户名、项目名，却想不起准确文件名。

MacList 只盯住这个时刻。

## 首次设置（只做一次）

MacList 自己的本地索引**默认关闭**。你没有明确选择文件夹，它就不会扫描文件夹。

1. 启动 MacList，从菜单栏图标按 macOS 正常流程授予“辅助功能”和“文件窗口控制”权限。
2. 在 MacList 菜单中点击 **选择索引文件夹…**。
3. 选择真正存放客户和项目资料的具体文件夹。整个系统、整个用户目录、普通 Library 等范围过大的根目录会被拒绝。
4. 等菜单状态显示“本地索引：已就绪”或“本地索引：部分完成”。达到保护上限或遇到文件系统访问错误时会明确显示部分完成；安全取得的结果仍可搜索，但不会伪装成完整结果。

MacList 只保存每个文件的**文件名、完整路径、修改时间**，以及记住所选文件夹所需的 macOS 授权书签；不读取文档正文。完整路径本身可能包含客户名、项目名等目录信息，因此索引和书签只保存在 MacList 的本机私有应用数据中。

资料移动或新增后，点击 **立即更新本地索引**。点击 **清空本地索引…** 会删除这些元数据和文件夹书签，但绝不会删除原文件。

> [!NOTE]
> “默认关闭”指 MacList 自己的文件夹扫描。macOS Spotlight 仍可能补充系统索引里已有的文件名和路径元数据。

## 日常操作流程

1. 你在微信、Apple Mail、Outlook 或其他应用里点击“上传文件 / 添加附件”。
2. macOS 文件选择窗口出现。
3. MacList 识别到可信的文件窗口后，把搜索栏安静地贴附过去；不打开 Finder，也不切换到另一个应用。
4. 直接输入客户名、项目名、文件名或路径片段；原位置展开候选清单，并显示文件名和所在目录。
5. 用方向键或鼠标选择候选，按回车。
6. 默认模式下，MacList 先精确选中文件，再确认原 Open-file 面板；附件进入当前聊天或邮件的待发送区。MacList 绝不会替你点击“发送”。

只要窗口属于 Save、选文件夹、未知类型或多选场景，或者会话已经过期、精确选中无法核对、默认按钮缺失或含义不唯一，MacList 就拒绝自动确认，保留原窗口让你手动处理。你也可以随时在菜单栏关闭 **选中文件后自动确认原窗口**，切换成“只选中、手动确认”。

主流程不要求 `⌥Space`，也不先跳到独立的 MacList 页面。`Esc` 只收起 MacList 浮层，不会关闭原文件窗口。

## 搜索从哪里来

MacList 合并两种只含元数据的候选来源：

- **用户授权的本地索引是主来源**：搜索你选定文件夹内的文件名和完整路径。因此即使忘了准确文件名，只输入客户文件夹或项目目录名称也能匹配。
- **Spotlight 是补充来源**：补充 macOS 系统索引已经知道的候选。两边返回同一个规范化完整路径时，以本地索引记录为准。

每次查询和每次索引刷新都有独立代次。旧索引任务、旧本地结果或上一条查询不能覆盖现在的候选清单。

## 为什么必须做成原生小程序

Skill 可以负责安装说明、诊断和验证，但不能持续监听 macOS 窗口、显示不激活自身应用的贴附面板，也不能安全控制另一个应用打开的系统文件窗口。因此：

- 核心体验：Swift + AppKit 原生菜单栏 App；
- 可选辅助：未来再提供安装和诊断 Skill。

## 技术结构

```text
MacListApp
├── DialogProcessDiscovery   从系统焦点发现独立文件面板进程
├── FileDialogMonitor         分开监听宿主和真实文件面板 PID
├── SearchPanelController     贴附搜索栏并合并当前查询结果
├── LocalIndexCoordinator     处理用户发起的选择、更新和清空
├── FileDialogBridge          把精确文件交回原窗口
└── AccessibilityPermission  不绕过 macOS TCC

MacListCore
├── AuthorizedFolderStore     私有保存带授权版本的 macOS 书签
├── LocalIndexRootPolicy      拒绝不安全或范围过大的根目录
├── LocalIndexService         用代次守住授权与重建生命周期
├── LocalFileIndexer          有上限的文件名/路径/修改时间扫描
├── LocalIndexProvider        本地索引主搜索源
├── SpotlightProvider         系统元数据补充源
├── SearchResultSet/Epoch     确定性合并与旧结果拒绝
└── DialogSelectionPolicy     路径验证与失败关闭的自动确认策略
```

macOS 10.15 以后，Open Panel 由独立进程绘制，外部应用拿不到宿主的 `NSOpenPanel` 对象。MacList 因此只能使用经过用户授权的系统辅助功能接口；不能确认当前窗口、权威动作或精确选中的规范化路径时会安全停止。

## 静默构建、验证与本机试用

需要 macOS 13+ 和 Swift 6：

```bash
git clone https://github.com/xffighting/maclist-actions.git
cd maclist-actions
./app/Scripts/verify.sh
```

验证脚本会运行无界面核心门禁；本机有完整 Xcode 时运行 XCTest；随后构建 release、生成本机临时签名的 `MacList.app`、校验 plist 和签名，并执行命令行 doctor。它不会启动图形界面。

GitHub Actions 永远保留为“每次推送都执行”的远端门禁。远端状态只认对应提交的实际工作流结果，不用本地验证结果代替。

只安装不启动，或者明确启动菜单栏预览版：

```bash
./app/Scripts/install-local.sh
./app/Scripts/install-local.sh --launch
```

默认安装到 `~/Applications/MacList.app`。第一条命令不会启动；只有显式传入 `--launch` 才会在后台启动。
安装或更新前先退出正在运行的 MacList，避免旧进程继续使用旧版本。

单独命令：

```bash
swift build --package-path app
./app/Scripts/all-smoke-tests.sh
./app/Scripts/build-app.sh release
```

## 隐私与安全边界

- 不上传文件、无遥测、无账号、无 API Key；
- 授权索引只保存文件名、完整路径、修改时间和文件夹书签，不读正文或候选文件内容；
- MacList 扫描默认关闭，只处理用户明确选择的文件夹，阻止符号链接逃逸，并拒绝危险的宽根目录；
- 缓存只有在授权版本与规范化根目录集合一致时才会被采用；建立前后还会核对根目录物理身份；
- 重新选文件夹、清空索引、关闭窗口或开始新搜索都会让旧异步任务失效，旧结果不能“复活”；
- “清空本地索引”只删除元数据和书签，绝不删除原文件；
- 不打开 Finder，不使用剪贴板注入或 AppleScript，不选择联系人、收件人或聊天，永不自动发送；自动确认只面向原始、当前、核对无误的单文件 Open 面板；
- 只有你主动点击“选择索引文件夹”时，设置流程才可能暂时激活 MacList；日常文件窗口流程不激活或切换应用；
- 候选交回时不打开文件，也不主动下载云盘占位文件；原文件窗口负责访问，MacList 只在有限时间内核对它选中的规范化 URL / 路径；
- Save、选文件夹、未知类型和多选窗口都不得自动确认；旧会话、无法核对精确选中、默认按钮缺失或按钮含义不唯一时也必须回退人工。Save 窗口不得自动提交，更不能自动覆盖文件。

## 常见问题

### 微信点击上传后会自动出现吗？

这是已经实现的主流程设计：监听系统焦点、找到独立文件面板的真实拥有者，证据达到阈值后才贴附。但新的真实微信回归仍然暂停，通过前不会写“已兼容微信”。

### 为什么没有候选文件清单？

先点菜单栏 MacList 图标，选择 **选择索引文件夹…**。如果状态是“部分完成”，安全取得的结果仍可搜索，但可能有文件夹无法访问或触发扫描上限；处理权限后点击 **立即更新本地索引**。Spotlight 只是补充，不能保证知道所有文件。

### 按回车会直接上传吗？

当前选定的默认模式会先选中经过核对的文件，再确认原单文件 Open 面板，让附件进入聊天或邮件的待发送区；它绝不会替你发送消息。任何安全条件不明确时，原窗口都会保留，改由你手动确认。你也可以在 MacList 菜单中关闭 **选中文件后自动确认原窗口**，恢复“只选中”。

### 自动确认已经在微信和邮件里验证了吗？

还没有。模式、一次性桥接、拒绝矩阵、偏好、构建和安装器已经通过静默门禁，但还没有运行标准系统面板、微信、Apple Mail、Outlook 的可视化回归。完成这些实测之前，项目不会承诺已经兼容。

### 会读取或上传我的文件吗？

不会。MacList 搜索的是本机元数据，没有文档上传路径。需要注意：完整路径也是元数据，可能暴露客户或项目目录名；你可以随时用 **清空本地索引…** 删除本机缓存和书签。
