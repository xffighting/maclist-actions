EXECUTIVE VIEW

从“找到文件”到“交给正确应用”。

Skill 作为开发与验收手册，不作为最终产品

Skill 无法提供后台索引、全局热键、原生结果窗、拖拽和 Quick Switch。

用户价值：辅助产品形态：否复用价值：高

GPL 对应源码、私有依赖与历史身份无法完整闭环时，独立干净镜像更安全。

发布风险：低可追溯性：高回滚：清晰
