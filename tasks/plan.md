# MacList 文件对话框版实施计划

1. 固化“上传窗口出现 → 自动贴附 → 模糊搜索 → 原窗口精确选中”的唯一主流程。
2. 分开建模宿主应用 PID、真实文件面板 PID、运行时键盘目标和会话 generation。
3. 用系统焦点轻探测触发深分类，为真实面板 PID 单独注册 AXObserver。
4. 实现不激活应用、不跨 Space 残留的贴附搜索栏。
5. 实现可取消、分阶段验证、默认只选中的文件回填事务。
6. 先完成纯逻辑、smoke、release 构建、静态禁用流程和文档门禁。
7. 获得用户许可后依次运行标准 Harness、微信、Apple Mail、Outlook 可见回归。
8. 真实回归稳定后，才评估自动最终确认、签名公证、Demo、tag 和 GitHub Release。
